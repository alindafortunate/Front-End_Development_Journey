🌍 Real-World Examples

🎯 Focus Indicator

outline is commonly used to show which element has keyboard focus.

The yellow outline shows focus without shifting the button

/* Focus state - no layout shift */
button:focus {
  outline: 3px solid #f59e0b;
  outline-offset: 2px;
}

🖱️ Hover Effect

outline creates hover effects without shifting content.

Hover over the buttons — outline appears without moving them!

/* Hover effect - no layout shift */
button:hover {
  outline: 3px solid #ef4444;
}

✨ Outline-Offset: Extra Control

📊 Border vs Outline: Complete Comparison

Feature Border Outline
Affects layout? ✅ Yes ❌ No
Takes up space? ✅ Yes ❌ No
Can be on individual sides? ✅ Yes (border-top, etc.) ❌ No (all sides only)
Can have rounded corners? ✅ Yes (border-radius) ❌ No (always rectangular)
Can use offset? ❌ No ✅ Yes (outline-offset)
Common use case Element borders, boxes Focus indicators, highlights

💡 When to Use Border vs Outline

Use border when:
  • You want the element to physically change size
  • You need different colors on each side
  • You want rounded corners (border-radius)
  • You're designing a box, card, or container
  • You want the border to be part of the element's structure
Use outline when:
  • You want a visual highlight without shifting layout
  • You're creating focus indicators for accessibility
  • You need a hover effect that doesn't push content
  • You want to draw attention without affecting layout
  • You need an offset (space between element and line)
