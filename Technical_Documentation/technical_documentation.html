Getting started with Python

Sample code for printing hello world include;

print('Hello World')

Here we have used an inbuilt python function called print() to print the words Hello World, though you too can develop custom functions.

Below are examples of custom functions.

          
          def add(a, b):
            return a+b
          
        
          
          def subtract(a, b):
            return a-b
          
        
          
          def multiply(a, b):
            return a*b
          
        
          
          def divide(a, b):
            return a/b

Below is how you call these functions.

          
          print(add(4, 5))
          print(subtract(4, 5))
          print(multiply(4, 5))
          print(divide(4, 5))
          print(add(5, 5))
